百度 TTS
云函数代理
STEP 01

获取 Access Token

云函数端通过 HTTPS 请求百度 OAuth 接口，获取 API 调用凭证

STEP 02

调用 TTS 合成音频

将非遗项目介绍文本（截断至 500 字）发送至百度 TTS API，获取 MP3 音频流

STEP 03

上传云存储

合成音频自动上传至云存储 images/audio/ 目录，返回可播放的临时链接
